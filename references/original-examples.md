# 原有术语与改写示例

本页保留原版 Skill 的全部术语表、改写对照和独立事实条目示例。使用时按[写作规则](../SKILL.md)保留原意，并结合上下文选择对应表述。

涉及具体指标、数字、机制或判断的改写，以原文或已有资料已提供这些信息为前提；例如“24 步训练后正确率变化为 0.05”需要上下文已明确指标为正确率。

## 术语类型与处理

| 类型 | 处理 |
| --- | --- |
| 标准术语 | 使用标准中文术语；首次出现时可保留英文原词 |
| API、模型、产品名称 | 保留名称，只改写解释性文字 |
| 双语术语 | 使用“中文标准术语（英文原词）”格式，保留原词用于检索 |
| 团队自定义术语 | 根据已确认的定义改写为直接描述；需要保留原词时，在首次出现处附定义 |
| 隐喻或口语 | 直接说明对象、动作、条件和结果 |
| 多义术语 | 结合上下文、英文原词和技术领域判断；信息不足时保留原词，并将确认程度写为“含义待确认” |
| 行业黑话或英文硬翻 | 根据实际对象、动作和条件改写；仅在属于正式名称时保留原词 |
| 单字术语 | 使用完整标准术语；含义不足时保留原词并标记确认程度 |

## 多义术语示例

| 原词 | 建议表述 | 处理条件 |
| --- | --- | --- |
| 相位 | 阶段 / 相位 | 流程状态使用“阶段”；信号或物理量使用“相位” |
| 刀 | 下一步操作 / 下一阶段 | 上下文明确时使用对应表述；上下文不足时保留原词并标记“含义待确认” |
| 满幅 / 岩稳 | 稳定触发 / 不稳定或未触发 | 按原文已确认的定义改写 |
| 动量 | 延续前序任务的倾向 | 确认对象为轨迹行为时使用 |
| 时态 | 轨迹中的时间关系 | 确认对象为轨迹时间信息时使用 |
| 拆步 | 将单步轨迹拆分为多个步骤 | 确认对象为轨迹结构时使用 |
| 活库、脏库、烘进快照 | 直接说明运行数据库、数据清理和 checkpoint 写入过程 | 先确认具体对象和动作，再改写 |

| 原表述 | 建议表述 | 处理条件 |

| 对号 | 对号入座 | 需要表达完整成语时使用 |

### 比喻表达

对应规则 4、5。

| 原表述 | 改写 |
| --- | --- |
| 血统 | 基座来源 |
| 8 个不同血统 | 8 个不同基座的模型 |
| 那是尺寸差异，不是血统差异 | 原有区间由 Qwen 的 14B、32B、72B 构成，差异来自参数量而非基座 |
| 已经吃掉一半空间 | 已覆盖一半区间 |
| 变成了一个认题目的检索器 | 退化为问题识别，与学习价值无关 |
| 挑出来的题目看上去健康得多 | 选中问题的截断比例更低 |
| 误差范围还盖着基准线 | 置信区间与基线重叠 |

涉及“问题识别”“学习价值”等判断时，以已有分析为依据。
